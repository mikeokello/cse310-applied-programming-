# cse310-applied-programming-

## Description
This project is a simple Hello World application created for the CSE310 Applied Programming course at BYU-Pathway Worldwide. It demonstrates the basic structure of a small software project and shows how code can be run from the terminal to produce output.

## Project Purpose
The purpose of this project is to establish a working development environment and confirm that the student can create, run, and share a small software program. The application prints a friendly greeting to the console and serves as a foundation for future programming assignments in the course.

## How to Run
1. Ensure that Node.js is installed on your computer.
2. Open a terminal in the project folder.
3. Run one of the following commands:

```bash
node index.js
```

or

```bash
npm start
```

## Program Output
```text
Hello World
```
