# CSE 310 - To-Do Manager - Kaizen Edition

## Overview
This is my Module #1 project for CSE 310 Applied Programming. It is a console-based To-Do Manager that uses JSON as a cloud-ready database. The app helps users practice continuous improvement (Kaizen) by managing small daily tasks.

This software demonstrates file I/O, JSON handling, data sorting, and menu-driven design in Python.

## How it Works
- Tasks are stored in `tasks.json` file (simulates cloud database)
- User can add tasks with priority (High/Med/Low)
- Tasks can be viewed sorted by priority
- Tasks can be marked complete or deleted
- Stats show completion rate for motivation
